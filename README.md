Smile Launcher (SLH) is a personal, non-commercial, portable Windows x64 launcher for Minecraft: Java Edition. It manages isolated game instances and allows users to browse CurseForge projects, find compatible files, resolve required dependencies and conflicts, import supported CurseForge modpack archives, and install permitted mods and resource packs into local instances.

All downloads are explicitly initiated by the user. SLH respects project distribution permissions, uses only download URLs supplied by CurseForge, validates available file hashes, and does not rehost CurseForge content.
